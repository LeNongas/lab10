# Dự án đặt phòng homestay

Ứng dụng gồm [máy chủ Spring Boot](homestay-monolith/README.md) và giao diện React trong `homestay-frontend`.

Chạy MySQL, sau đó chạy `vn.homestay.HomestayApplication` bằng IntelliJ IDEA (JDK 17, cổng 8084). Trong Terminal tại thư mục này, chạy `npm run dev` và mở `http://localhost:5173`.
